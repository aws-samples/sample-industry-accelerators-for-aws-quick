# Life sciences accelerators

| Accelerator | What it adds to AWS Quick |
| --- | --- |
| [Scientific Computing Sandbox](scientific-computing-sandbox/) | Per-user, network-isolated Python sandboxes with scientific environments for cheminformatics, imaging, genomics, transcriptomics and single-cell analysis |
| [Bio viewers](bio-viewers/) | Interactive protein structure, sequence alignment and DICOM image viewers (MCP Apps) |

Each accelerator is an independent CDK app. See its README to deploy it, and
[docs/authentication.md](../../docs/authentication.md) to set up sign-in.
